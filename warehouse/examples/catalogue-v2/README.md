# Синтетичні приклади CarPot Catalogue Import v2

**Усі пропозиції, OEM, артикули, URL і ціни в цьому каталозі синтетичні. Це не ринкові дані Aleto. Використовуйте тільки локальний тестовий workspace.** Реальний історичний пакет Aleto v1 залишається окремо в `backend/app/data/aleto/v1/`.

1. Завантажте `volvo-initial.csv`, виконайте preview, підтвердьте apply — одна синтетична пропозиція.
2. Завантажте `volvo-increment.csv`: стара пропозиція, нове спостереження її ціни, дві нові пропозиції, нова підкатегорія, відсутні ціни та неоднозначне `Комп`.
3. Для `Комп` явно виберіть «пропустити зіставлення» і побудуйте новий preview. Це зберігає пропозицію, модель і raw-шлях без вигаданого канонічного типу. Підтвердьте apply: загалом три пропозиції та чотири спостереження цін.
4. Повторіть той самий інкрементальний файл: відповідність `Комп` знову потребує явного рішення, але нових/оновлених сутностей після skip немає. Джерельні дані не дублюються.
5. Завантажте `bmw-audi.csv` або `bmw-audi.zip`: обидва формати дають однакові дві додаткові пропозиції з марками BMW та Audi. Повтор другого формату не дублює вже застосовані дані.

`manifest.example.json` — вміст manifest усередині ZIP. Якщо CSV змінено, обчисліть новий SHA-256 та створіть новий ZIP; старий manifest не підійде. Завантаження зміненого файла створює новий import job і вимагає нового preview.
