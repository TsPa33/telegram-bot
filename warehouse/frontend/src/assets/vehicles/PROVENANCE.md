# Generic vehicle artwork provenance — 2026-10-24

These are generated generic vehicle illustrations, not photographs of actual
Warehouse donors or verified depictions of Volvo, BMW, Chevrolet or any model.
No third-party photograph/reference, scraped image, brand emblem or paid vehicle
image API was used. No external source is contacted by the frontend.

Source: OpenAI image generation in this task. Original prompts requested anonymous
unbranded silver vehicles, realistic proportions, detailed wheels/glass/lights,
transparent backgrounds, no logos, text, watermarks, environment or UI.

- `generic-suv.webp`: generated side-profile generic crossover/SUV. The final
  side view was generated using our own earlier generic SUV output as reference.
  Original output: `exec-69228273-a281-4a84-ad9a-56574896c277.png`.
- `generic-unknown.webp`: generated neutral generic passenger car, front/side
  three-quarter view. Original output:
  `exec-7aaecb3d-fe62-4557-b061-9c2222edcdf5.png`.

Use is subject to the applicable OpenAI terms for generated output, including
https://openai.com/policies/terms-of-use/ (provenance reference, not a card fetch).
No third-party asset license or exclusive copyright ownership is asserted. These
assets are approved here ONLY as generic decorative fallbacks, never as exact
model or generation illustrations. They must not be relabelled as such.

Optimization: existing alpha transparency preserved; transparent padding trimmed;
resized using Lanczos and encoded WebP quality 84, method 6. Main width 960px,
responsive variant 480px. No retouching to claim an exact model. UI applies
monochrome styling, opacity and a soft edge mask. `metadata.json` records actual
dimensions, byte counts and SHA-256 for the four shipped files. Full-resolution
originals remain outside Git; only optimized assets are shipped.

To add a model image, obtain documented rights allowing product/commercial use,
verify its model, generation and exact production-year coverage, and record its
specific source/license/attribution in the manifest. Generated approximate
likenesses do not establish verified model/generation accuracy.
