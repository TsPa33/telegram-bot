# Артикули та OEM: цільове UX-виправлення

База: ff5161ee9fbbbac5606360f52c770e33b123034d.

- «Номери» → «Артикули та OEM». Панель показується для конкретної деталі,
  має закриття й спочатку читає збережені PostgreSQL snapshots без токенів.
- Зайві дії отримання над таблицею видалені. Один контроль отримання нових
  артикулів у панелі; тариф/умови мають бути підтверджені сервером. Підтвердження
  розміщене поруч, а не над довгою таблицею. Зміна деталі скасовує старе підтвердження.
- Порожній успішний snapshot — «пропозицій не знайдено», не помилка відновлення.
  Незавершені/помилкові запити показують конкретну помилку, без paid retry.
- Метрики backend: типи з checklist; варіанти — фактична довжина snapshot arrays;
  призначені артикули/OEM — усі активні картки цього донора; відновлення —
  distinct типи з відсутнім історичним snapshot або невирішеним останнім запитом.
  Старий невдалий запит не рахується після успішного нового.
- OEM окремо. Підтвердженого OEM endpoint немає: автоматичне отримання вимкнене,
  ручне введення/збереження залишається. OEM не підтверджує VIN.
- Відповідь articles може містити characteristics/attributes/technical_details/
  description: надані скалярні значення зберігаються у typed snapshot і показуються.
  Це не новий endpoint і не доказ fitment. Оригінальний дозволений payload
  залишається в чинному durable store; показ обмежений 40 полями по 2000 символів.
- Англійське name_uk більше не перекриває наявний reviewed український словник.
  Оригінал лишається для пошуку. Невідомі назви позначені для уточнення; не
  генеруємо вигаданих перекладів. Українську назву можна зберегти в checklist.
  DeepL автоматично не викликається; тестових витрат на переклад немає.
- Призначення використовує чинний перевірений API; після збереження оновлюються
  read model, таблиця та inventory event. Пошук показує номер і виробника.

Категоризатор, групування, колонки, stock/finance logic не змінені. CSS змінює
лише перенесення довшого напису кнопки та положення кнопки закриття панелі.
Міграцій немає; head залишається bd18a9f37c20.
