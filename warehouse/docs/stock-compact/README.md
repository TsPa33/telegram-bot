# Компактний склад

## Зміни

- Один стандартний список на всю ширину, без статистичних бічних панелей, секцій і фільтрів локацій. Історичні значення місць зберігання не видаляються; редагування картки їх зберігає.
- Шапка з фактичною кількістю backend для поточного відбору, додаванням і CSV-експортом. Сканер не імітується.
- Пошук назви/OEM/артикула, категорія, фізичний стан, наявність; донор у додаткових фільтрах. Серверна пагінація 25/50/100, backend total, збереження вибору між сторінками. Повний відбір завантажується лише за явною дією експорту.
- Таблиця повторно використовує InventoryPartRow, InventoryQuantity, SellerPriceEditor та PartActionMenu. Донор відкриває картку авто; залишок, OEM, артикул/виробник і ціна відображають фактичні дані. CSS scoped до стандартного складу; виправлено конфлікт старого `.empty` зі статусом нульового залишку.
- Швидкі дії для вибраних позицій. Кількість, ціна, номери та категорія редагуються покроково для кожної конкретної картки з явним збереженням. Пропуск не змінює картку; вихід/закриття припиняє подальше редагування. Це не атомарне масове застосування одного значення до всіх.
- Архівування до 100 позицій використовує чинний backend bulk endpoint і окреме підтвердження з причиною. Фізичного видалення немає.
- На iPhone таблиця перетворюється на картки; швидкі дії згорнуті, кнопки залишку горизонтальні.

## Файли

`InventoryWorkspace.tsx`, `SalesWorkspace.tsx`, `InventoryPartsList.tsx`, `StockBulkDialog.tsx`, нові `InventorySelectionEditor.tsx`, `inventory-compact.css`, цільові тести.

Backend, schema, migrations, продажі, фінансові розрахунки та розбір не змінені. Для пошуку збережено попереднє компонування; спільна назва донора тепер є посиланням.
