# CarPot OEM — автоматичний вибір модифікації

Базові PR №562–565. Автоматичний пошук перевіряє марку, модель, інтервал років і відомі характеристики, ранжує наявні збіги та стабільно розв'язує нічию за source ID. Вибір з довідника позначено `auto_assumed`, `vin_verified=false`.

Селектор у картці дозволяє змінити модифікацію тієї самої моделі. План повторно використовує збережені PRD-зв'язки. Рядки без надійного зв'язку з PRD можуть отримати OEM за одним перевіреним типом із точною назвою та шляхом категорії, з урахуванням вимог сторони встановлення. Записи про зміну модифікації та попередній автоматичний OEM зберігаються в журналі операцій. Ручні зміни, ручне очищення, резерви й картки з продажами захищені від автоматичної заміни.

Якщо для вибраної модифікації номер відсутній, Warehouse шукає кандидатів у знімках тієї самої моделі та виробника за тим самим PRD. Кандидати інших модифікацій мають статус `unconfirmed`, відображаються окремо та не копіюються до складу.

Звіт `/api/v1/oem/admin/coverage` розрізняє автоматичні OEM вибраної модифікації, ручний вибір у плані й позиції з непідтвердженими кандидатами інших модифікацій. Для контрольного заміру потрібна авторизована сесія адміністратора до і після циклу збагачення.
