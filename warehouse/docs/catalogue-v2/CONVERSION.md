# Офлайн-конвертер Aleto → Catalogue v2

Запуск із `warehouse/backend` у Python environment із залежностями Warehouse. Конвертер не відкриває Warehouse DB і не виконує мережевих запитів.

```bash
python -m app.services.catalogue_convert /path/parser.csv --output /tmp/volvo-v2.zip --report /tmp/volvo-v2-report.json
# Або каталог із трьома підготовленими файлами:
python -m app.services.catalogue_convert /path/prepared --output /tmp/prepared-v2.zip --report /tmp/prepared-v2-report.json
```

Вихідні файли не перезаписуються. ZIP містить лише `manifest.json` і `catalogue.csv`; SHA-256 CSV перевіряється штатним валідатором. Звіт містить SHA-256 входів, CSV, ZIP та кількість пропозицій, модельних зв’язків і шляхів.

Профіль parser CSV: UTF-8/BOM, кома, обов’язкові колонки `article,model,category,subcategory,title,url,checked_at`. OEM, ціни, стан та всі додаткові колонки зберігаються. `checked_at` має містити timezone. Всі початкові значення, включно з пробілами та невідомими колонками, зберігаються у `source_record`; канонічні поля окремо проходять нормалізацію v2. Некоректні значення чи перевищення лімітів відхиляються, не обрізаються.

Профіль prepared: `offers.csv` (article,title,url,checked_at та додаткові поля), `applications.csv` (model,article), `taxonomy_paths.csv` (model,article,category_uk,category_source,subcategory_raw та додаткові поля). Зв’язки перевіряються; відсутні пропозиції/шляхи, дублікати ключів та суперечливі спільні колонки блокують конвертацію.

Без параметрів розпізнаються тільки повні назви Volvo XC40/XC60/XC90. Для іншої марки потрібен явний `--manufacturer 'Land Rover'`, а модель у файлі повинна починатися з цієї марки. Роки, покоління, сумісність, сторона та позиція не вгадуються. Невідомі українські категорії/підкатегорії потребують ручного підтвердження у preview.

Реальний пакет A перевірений: 7 246 пропозицій, 10 112 модельних зв’язків, 14 400 шляхів. Усі канонічні рядки конвертації prepared CSV збігаються з існуючим v1-адаптером. Реальний B (10 222 пропозиції) відсутній: його схема, конвертація й дельта ще потребують окремої перевірки. Орієнтири 2 976 / 4 212 / 58 / 114 не є результатами цього запуску. Після отримання B спочатку конвертація та preview з перевіркою звіту; жодного автоматичного apply.
