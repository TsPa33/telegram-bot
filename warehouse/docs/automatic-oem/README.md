# Automatic OEM enrichment

This supersedes the interactive Volvo pilot and PR #526. No user import controls.
A dedicated Warehouse API thread scans active donors from all workspaces every 120s, with a PostgreSQL advisory lock and bounded batches. It uses free Catalogue API, not Plan.Parts. New and existing donors are picked up without a browser session. Only proven source identities (pinned global/saved selection or the narrow reviewed XC90 pilot) and exact reviewed type matches qualify. No inference from a brand alone. Current live Catalogue directory only has the 107555 snapshot; the general OEM table is not a fitment graph. More snapshots are needed for other unbound modifications.
The legacy volvo_oem_references JSON key stores all makes for backwards compatibility. Selected reference and alternatives remain source-pinned; no automatic overwrite of manual or previous selections. Receipt copies a valid reference into an empty card; stock metadata changes are audited, no stock quantities/prices or schema changes. The default number is ranked by independent suppliers then lexical order, not by OE supersession or VIN verification. Worker defaults on in Warehouse staging if Catalogue credentials exist; off elsewhere unless WAREHOUSE_AUTO_OEM_ENABLED=true. No change to import-worker or Catalogue deployment. Disable with false. All live mutations require explicit release approval; tests only use disposable data.
