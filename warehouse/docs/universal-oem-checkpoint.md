# CarPot Universal OEM — контрольна точка

- Попередній Catalogue #558 і Warehouse #559 залишаються базою змін. Повторне створення плану, перенесення OEM при прийманні та редактор альтернатив уже існували.
- Catalogue читає легковий граф із `article_links` типу 2 і отримує OEM за точним ключем постачальник + артикул + виробник з `article_oe`. URL пакетної вибірки прив'язаний до SHA знімка й обмежений 12 типами та 3000 зв'язками. Імпорт зберігає оригінальні PRD та запобігає перезапису опублікованих знімків. Для опублікованих авто додає OEM спільних перевірених зв'язків і рахує нові зв'язки, що чекають звірки версії.
- Warehouse використовує пакетний endpoint із сумісним резервним шляхом і відображає «OEM уточнюється». Адміністратор може отримати звіт активного робочого простору через `/api/v1/oem/admin/coverage?workspace_stock=true` з необов'язковим `vehicle_id`. Це звіт по складських фізичних позиціях із додатним залишком.
- Локальна Windows MySQL недоступна з Codex Cloud. Вихідні дані від замовника. XC60 595 позицій з 0 OEM, XC90 16 OEM-зв'язків на 196 позицій, DAF XF 227 позицій з 0 OEM. Потрібно звірити, що знаменники рахували однакові типи позицій. Післярелізне покриття не виміряне.
- Відсутні фактичний аудит структури вантажного каталогу, затверджені зіставлення історичних рядків без стабільного ID, перевірка всіх доступних модифікацій та розбивка непідтверджених кандидатів за причинами.

## Трансфер із Windows

Один скрипт, `catalogue/transfer-oem-graph.ps1`, у [Catalogue PR #562](https://github.com/TsPa33/telegram-bot/pull/562). Приймає перелік підтверджених легкових source modification ID. Без `-ApplyToStaging` експортує лише локальні артефакти. Для запису потрібен уже відкритий локальний тунель до Catalogue staging і UUID сервера, звірений незалежно у підтвердженому staging MySQL. Скрипт перевіряє UUID в тому самому з'єднанні перед записом. PowerShell і живий MySQL не доступні в цьому Linux workspace.

```powershell
.\catalogue\transfer-oem-graph.ps1 -ModificationId 107555
```

Для XC60 спершу підтвердити точний source modification ID. Додавати лише підтверджені ID. Окремий порт тунелю від 3306 обов'язковий.
